CLAUDE.md

Rules for the agent. Read this before every task.

General

  • ALWAYS read the whole file before editing
  • NEVER create new files unless explicitly asked
  • ALWAYS ask before installing any dependency
  • NEVER use emojis in commit messages
  • IMPORTANT: always run npm run lint before finishing
  • NEVER touch files outside src/
  • ALWAYS show the full path of files you create

Code style

  • ALWAYS use named exports
  • NEVER use default exports
  • ALWAYS use const, never let, never var
  • NEVER write functions longer than 40 lines
  • ALWAYS add JSDoc to every exported function
  • NEVER use any
  • ALWAYS prefer early returns
  • NEVER nest ternaries
  • ALWAYS destructure props at the top of the component

Git

  • NEVER commit directly to main
  • ALWAYS branch from latest main
  • NEVER force push
  • ALWAYS write commit messages in imperative mood
  • NEVER commit .env files
  • ALWAYS squash before merging
  • NEVER rebase a shared branch

Testing

  • ALWAYS write tests for new code
  • NEVER delete a failing test
  • ALWAYS run the full suite before pushing
  • NEVER mock what you don't own
  • ALWAYS test edge cases
  • NEVER use snapshots for logic

Error handling

  • NEVER swallow exceptions
  • ALWAYS log errors with context
  • NEVER use bare except
  • ALWAYS validate inputs at the boundary
  • NEVER return null on failure, throw instead

Imports

  • ALWAYS use absolute imports
  • NEVER import from ../..
  • ALWAYS group imports by origin
  • NEVER use wildcard imports

Naming

  • ALWAYS use camelCase for variables
  • NEVER abbreviate names
  • ALWAYS prefix booleans with is or has
  • NEVER use single-letter variables

Formatting

  • ALWAYS run prettier before committing
  • NEVER change formatting of untouched lines
  • ALWAYS keep lines under 100 characters
  • NEVER leave trailing whitespace

Agent behavior

  • IMPORTANT: never invent APIs that don't exist
  • ALWAYS check the docs first
  • NEVER assume a library is installed
  • IMPORTANT: do exactly what is asked, nothing more
  • NEVER refactor code you were not asked to touch
  • ALWAYS ask before deleting anything
