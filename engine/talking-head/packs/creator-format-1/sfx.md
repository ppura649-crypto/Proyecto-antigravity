# Creator Format 1 pack: the sound palette

Chosen by the creator over several reels. Closed: a moment that seems to want another sound
gets one of these or silence; a new file enters only after the creator has heard it in an A/B and said
yes. Files in `motion-lab/public/audio/sfx/`. The everyday accents sit slightly louder than
instinct puts them; the riser is the one sound allowed clearly above the voice.

| moment | file | peak offset |
|---|---|---|
| the punch of the hook, a named idea landing (climax on the word) | `popular-riser-metallic-sound-effect-trimmed.mp3` | 1350 ms |
| a highlight sweep, a line flipping to the accent | `mixkit-arrow-whoosh-1491.wav` | 270 ms |
| an item counted, a chip or block landing, a question mark | `mixkit-modern-technology-select-3124.wav` | 70 ms |
| a number arriving | `mixkit-message-pop-alert-2354.mp3` | 0 |
| a whole-screen takeover (low) | `mixkit-air-woosh-1489.wav` | 675 ms |
| the save CTA: the icon swap, then the real click | `mixkit-dry-pop-up-notification-alert-2356.wav`, `computer-mouse-click-352734.mp3` | 0, 160 ms |
| a physical gag gets its physical sound (paper crumpled) | `mixkit-quick-paper-crumple-2996.mp3` | 260 ms |

Outside the palette for good: cinematic booms, rising and falling swooshes on a moving object,
any whoosh on a card or a transition.
