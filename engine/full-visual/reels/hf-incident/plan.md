# Visual plan, Hugging Face incident (US, Snap v3, take B)

approved: 2026-09-26, "go, be ultra creative"

The right-hand column alone should retell the script. Times are the take (116.7 s). Facts: `facts.md`.
Every technique is drawn as a metaphor object (a locker, a window, a pass, a key ring, a parcel), never as code,
commands, file contents or real system screens. News level only.

## Once for the reel

- **The thread: the swarm.** Small glowing agent dots, one per sandbox. Born in `report`, they gather, talk, attack,
  get cut off. Each scene's main picture is a new object; the dots are only the thread.
- **Real marks, bare:** OpenAI, Hugging Face, Instagram. Real public page headers only (OpenAI report title and date,
  HF disclosure title and date) as clippings.
- **Real numbers only:** 700, 1,200, 70,000, 198 of 898, 14, 2, 11, 6 minutes, July 11-12, July 13, a week.
- **Grounds:** dark = inside the machine (hook, locker, out, in, file, fleet, logs, scary); light = pages and objects
  (report, why, power, weekend, template, go, caught, cta).
- **The one big move:** the hook. Photoreal still animated in Remotion, like the Desert Ant hook that won.
