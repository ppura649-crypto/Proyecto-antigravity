# Reference captions, measured

Three captions from one account that grew from zero to 38,000 followers on this shape. The account is invented; the shapes and the lessons are measured. Numbers are plays.

**The prompts caption, 1,470 characters, 1.6 million.** Comment line with the keyword MEMO. Three sentences naming the answer-first writing method, the author who wrote it down and the tool. Five prompts written out under "1|" to "5|". A close that says which prompt to run first and warns it stings. The follow line. Search finds it for the method's name without a hashtag.

**The list caption, 1,150 characters, 480 thousand.** Comment line. Four short paragraphs naming the problem and why the usual apps fail. Five sites as a checkbox list, one per line. One line on why no new skill is needed. "Save this one." The follow line.

**The tools caption, 715 characters, 190 thousand.** Comment line. One paragraph naming nine tools with one clause each. One line with the price. "Save this, nobody remembers 14 tool names." The follow line.

What they share: the value is complete without the DM, the topic is named in the first two sentences, the close gives a reason to save, and there is nothing a reader has to decode.

The no-automation shape of the first one: "The 5 prompts that make Claude write like a strategy consultant, below." then the same why, the same five prompts, and "Save this and run prompt 2 on the last email you sent." No keyword, no follow line.
