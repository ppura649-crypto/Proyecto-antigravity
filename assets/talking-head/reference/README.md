# The reference reels

Six finished reels judged the best by far. They are the bar: things to look at
before a plan is written, never a description to trust and never a template to copy. The high-level
pattern across the six is what travels; the objects belong to their transcripts.

Each reel has a contact sheet (`<name>.sheet.png`, one frame every 2.5 seconds) and the plan it was
built from (`<name>.plan.md`). The videos themselves are large and travel beside the pack in
`assets/reference/videos/` when the install carries them; the sheets are enough to read the grammar.

## What all six share

- Real things wherever a real thing exists: a real file built then shot and scrolled, a real page, a
  real paper, real code, a chart from real numbers in the notebook look. Realism is what makes the
  reel trustworthy; light research before the plan exists to find those real things.
- Creative and in sync: the best object and motion for these exact words, entering on the word,
  leaving on the idea's last word.
- Instruments and real things, cards only where the idea is a thing to read. Black plates on a dark
  room, white on a bright wall, frameless objects on both. Never a box with text.
- Every picture read as a still over the real footage, at card scale, three to five rounds, before
  anyone else saw it.
- Sound, where the creator wanted it, sparse and tiny, on meaning, decided after the pictures.

## How to use them

Before writing a plan, open two sheets and read them frame by frame at full size: what the object
is, how it moves on its word, how long it lives, where the screen is bare and why. Then open the
matching plan and read the rows that produced the frames you liked. Then close them and write for
this transcript. The same object on a different subject is the failure the refinement pattern
describes; the same discipline is the point.
